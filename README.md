# Daily Earnings

A mobile-friendly daily earnings calculator. Enter your shift start time, hourly pay, and unpaid break minutes to see estimated earnings in CAD. Settings are saved locally in your browser.

## Publish with GitHub Pages

1. Open repository **Settings** → **Pages**.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Wait for GitHub Pages to publish the site.

## Add to iPhone Home Screen

1. Open the published site in Safari.
2. Tap Share → Add to Home Screen → Add.

The app updates while open at the selected 1-, 5-, or 10-minute interval and refreshes when you return to it. iOS may suspend background activity; this is not a native live widget. Earnings are estimates, not payroll records.
